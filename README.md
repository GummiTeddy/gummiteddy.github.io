# Siqi Dai — personal homepage

Live at https://gummiteddy.github.io/.

GitHub Pages publishes the root of the `public` branch. Maintain the current homepage directly in `index.html` and `css/home.css`; no build step, JavaScript, or third-party frontend dependencies are needed. The `source` branch contains the previous Hugo site and is historical; rebuilding it will not reproduce this homepage.

## Update and preview

- Edit `index.html` for profile, experience, projects, publications, and links.
- Edit `css/home.css` for responsive styles.
- Replace `files/Resume_SiqiDai.pdf` when a new résumé is available.
- Run `python3 -m http.server 8000` here, then open http://localhost:8000/.
- Check desktop and mobile layouts, navigation anchors, and résumé access before pushing to `public`.

The September 2026 update uses the provided résumé. The original résumé PDF is provided unchanged.

Older Hugo-generated pages and assets remain at their original URLs for existing links. They are not the source of the current homepage.
